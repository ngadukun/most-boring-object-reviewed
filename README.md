One line (98 characters, limit 200): a funny, true review of the dullest
everyday object — a doorstop. Its whole job is sitting still, and the joke
is that it does that job better than any gadget.

Entry:

> Doorstop review: it has one job, does it silently, and has never once asked for a software update.

`main.ts` writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`).
